## Mapa de questões por seção

O arquivo questions.md do simulado GenAI é uma sequência contínua (uma questão por cenário). Associe as questões erradas ao blueprint de 6 domínios com base no assunto do cenário.

| Tópico do cenário | Domínio oficial correspondente (peso) |
| :--- | :--- |
| Engenharia de prompts / chains / agentes / recuperação em tempo de execução | Application Development (30 %) |
| Mosaic AI FMAPI / MLflow para GenAI / Model Serving / Unity AI Gateway | Assembling and Deploying Applications (22 %) |
| Arquitetura RAG / RAG básico versus avançado / compensações na seleção de modelos | Design Applications (14 %) |
| Divisão em chunks / embeddings / criação de índices do Vector Search | Data Preparation (14 %) |
| Avaliação do MLflow / LLM como juiz / tabelas de inferência / desvio | Evaluation and Monitoring (12 %) |
| UC para ativos de IA / tratamento de PII / segurança de conteúdo / políticas do AI Gateway | Governance (8 %) |
| Atualização: GOV-1, GOV-2 | Governance (8 %) |
| Atualização: AGENT-1 | Assembling and Deploying Applications (22 %) |
| Atualização: GW-1 | Assembling and Deploying Applications (22 %) — configuração de tráfego do Model Serving |
| Atualização: EVAL-1 | Evaluation and Monitoring (12 %) |

## Plano de estudos conforme o número de erros (simulado de 45 questões)

| Erros | Situação | Ação |
| :---: | :--- | :--- |
| **0–5** (≥ 88 %) | Excelente | Agende o exame |
| **6–9** (80–87 %) | Provavelmente aprovado | Reforce os 2 domínios mais fracos |
| **10–13** (72–78 %) | No limite | Estude com foco por 1–2 semanas |
| **14–18** (60–70 %) | Ainda não está pronto | Faça uma revisão abrangente por 3–4 semanas |
| **19+** (< 60 %) | Lacuna significativa | Recomece pelos fundamentos de RAG / Vector Search |

## Armadilhas de maior impacto

- **Application Development (30 %)** é o maior bloco — chains, agentes, padrões de geração aumentada por recuperação e Vector Search em tempo de execução.
- **Aplicação composta de IA = um endpoint, não N microsserviços** — o empacotamento importa.
- **`ResponsesAgent` (subclass) + `agents.deploy()`** é o fluxo atual de MLflow + Agent Framework; `ChatModel` está obsoleto.
- **Unity AI Gateway tem 6 categorias de políticas** — limites de taxa, divisão de tráfego, registro de payloads, rastreamento de uso, guardrails e fallbacks.
- **PII deve ser redigida antes da geração dos embeddings**, não durante a recuperação (armadilha de Governance).
- **Inference Tables = registro oficial de auditoria** para qualquer endpoint em serving.
